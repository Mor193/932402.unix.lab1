# Лабораторная работа №1: Скрипт сборки на POSIX Shell

POSIX-совместимый shell-скрипт (`build.sh`) для автоматической компиляции исходных файлов (C, C++, TeX) в изолированном временном каталоге.

## Основные возможности
* **Анализ директивы:** парсинг имени выходного файла из комментария формата `// Output: <name>`, `% Output: <name>` или `# Output: <name>`.
* **Песочница:** сборка производится во временной директории, созданной через `mktemp -d`. Все промежуточные артефакты остаются в ней.
* **Гарантированная очистка:** перехват сигналов завершения (`EXIT`, `INT`, `TERM`, `HUP`) через `trap` с гарантированным удалением временной директории.
* **Размещение результата:** готовый файл перемещается строго в каталог к исходному файлу.

## Использование

```sh
# Выдача прав на выполнение
chmod +x build.sh

# Запуск сборки
./build.sh main.cpp
